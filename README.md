# ✏️ AI 实验随手记 (AI Experiment Memo)

随手记录想法、灵感和 AI 实验的备忘录——单文件 HTML,零依赖,数据留在浏览器,一键导出 Markdown 做内容素材。

**它不是打卡 App,而是一个真实的工作与生活日志**:里面记录的每一次想法、每一场实验,都是真实发生的事。记录攒成素材,周末导出就是一篇帖子。

## ✨ 功能

| 功能 | 说明 |
|------|------|
| ⚡ 快记模式 | 顶部输入框 + 可做素材勾选,回车 3 秒保存 |
| 📋 贴文字转记录 | 粘贴在别处写的想法,自动提取要点生成记录 |
| 📊 年度热力图 | GitHub 风格,记录密度一眼可见 |
| 🔥 连续记录 streak | 7/14/30/100 天成就徽章 |
| ⭐ 效果评分 | 给每条记录打分,导出带星级 |
| 📈 数据看板 | 7 天趋势、素材候选汇总 |
| 📌 素材标记 | 快记勾选 / 详情勾选 / 贴文字自动标记,统计卡点击查看全部 |
| 🌙 深色模式 | 一键切换,记住偏好 |
| 📤 导出 Markdown | 本周记录一键导出,直接当帖子素材(含省时统计) |
| 🔄 合并导入 | 多设备数据合流,按 id / 日期+内容去重 |

## 🚀 使用

1. 下载 `index.html`,双击浏览器打开即用
2. 无需安装、无网络依赖、零依赖纯原生 HTML+JS
3. 数据存在浏览器 localStorage,**不会上传到任何服务器**

### 在线版

GitHub Pages 托管,手机/电脑浏览器直接打开(可"添加到主屏幕"当 App):
**https://islandmyself.github.io/ai-experiment-log/**

### 跨设备使用

- 把 HTML 发到手机(如微信文件传输助手),浏览器打开即可快记
- 每周在主力设备导出 JSON 备份,换设备导入时自动**合并去重**,不覆盖

## 📋 数据字段

日期 / AI工具 / 记了什么 / 人工耗时 vs AI耗时 / 结果数据 / 心得翻车 / 是否可做素材 / 评分

## 💭 为什么做这个

跨境电商运营者把 AI 用进日常工作的过程中,顺手记下想法、发现和实验。**记录本身即内容**——真实、有数字、有翻车。

## ⚠️ 隐私说明

- 所有记录只存在你打开它的浏览器里,本仓库不收集、不存储任何数据
- 备份 JSON 是纯本地文件,请自己保管
