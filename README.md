# 🤖 AI 店铺实验记录 (AI Store Experiment Log)

跨境电商运营者的 **AI 提效记录工具**——每天 2 分钟,记下 AI 帮你干的活、省的时间、翻的车。记录攒成素材,周末导出就是一篇帖子。

**这不是一个"打卡 App",而是一个真实的工作日志**:里面记录的每一次实验,都是店铺运营里真实发生的事。

## ✨ 功能

| 功能 | 说明 |
|------|------|
| ⚡ 快记模式 | 顶部输入框 + 环节下拉,回车 3 秒保存 |
| 📊 年度热力图 | GitHub 风格,记录密度一眼可见 |
| 🔥 连续记录 streak | 7/14/30/100 天成就徽章 |
| ⭐ 效果评分 | 每次实验给 AI 打 1-5 星,导出带星级 |
| 📈 数据看板 | 环节分布、7 天趋势、素材候选汇总 |
| 🌙 深色模式 | 一键切换,记住偏好 |
| 📤 导出 Markdown | 本周记录一键导出,直接当帖子素材(含省时统计) |
| 🔄 合并导入 | 多设备数据合流,按 id / 日期+动作去重 |

## 🚀 使用

1. 下载 `index.html`,双击浏览器打开即用
2. 无需安装、无网络依赖、零依赖纯原生 HTML+JS
3. 数据存在浏览器 localStorage,**不会上传到任何服务器**

### 在线版

GitHub Pages 托管,手机/电脑浏览器直接打开(可"添加到主屏幕"当 App):
**https://islandmyself.github.io/ai-experiment-log/**

### 跨设备使用

- 把 HTML 发到手机(如微信文件传输助手),浏览器打开即可快记
- 每周在主力设备导出 JSON 备份,换设备导入时自动**合并去重**,不覆盖

## 📋 数据字段

日期 / 工作环节(写listing·客服·做图·选品·广告分析·数据分析·效率工具·AI学习)/ AI工具 / 干了什么 / 人工耗时 vs AI耗时 / 结果数据 / 心得翻车 / 是否可做素材 / AI表现评分

## 💭 为什么做这个

在跨境电商店铺里,把能交给 AI 的活一件件试一遍,记录过程。**记录本身即内容**——真实、有数字、有翻车。

## ⚠️ 隐私说明

- 所有记录只存在你打开它的浏览器里,本仓库不收集、不存储任何数据
- 备份 JSON 是纯本地文件,请自己保管
